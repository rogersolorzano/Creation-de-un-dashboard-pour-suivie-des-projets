# Création d'un Dashboard Tableau pour visualiser les progrès des projets

## Description
Ce projet a consisté à concevoir un tableau de bord interactif avec Tableau afin de visualiser les progrès de l’entreprise à travers des indicateurs clés.

## Objectifs
Centraliser et structurer les données de performance de l’entreprise pour un accès rapide et intuitif.
Créer des visualisations interactives permettant d’explorer l’évolution des indicateurs dans le temps.
Offrir une navigation simple et dynamique avec des filtres personnalisables pour répondre aux différentes attentes des utilisateurs.
Fournir un outil de pilotage efficace, accessible aux équipes techniques et aux managers.

## Instructions pour reproduire le dashboard
Ouvrir le fichier Tableau dashboard_progres.twbx disponible dans le dossier /dashboard.
Vérifier que les sources de données liées (fichiers Excel ou CSV dans /data) sont accessibles et actualisées.
Utiliser Tableau Desktop (version recommandée) pour interagir avec le tableau de bord.
Explorer les différents onglets, appliquer les filtres dynamiques et analyser les indicateurs.
Adapter les données ou visualisations si besoin en modifiant les sources ou feuilles de calcul.

## Outils utilisés
Tableau Desktop (version recommandée).
Données sources fournies au format CSV/Excel.
Fonctionnalités Tableau : filtres dynamiques, graphiques combinés, actions interactives.

## Résultats techniques
Dashboard interactif illustrant la progression des indicateurs clés selon les périodes et les services.
Visualisations dynamiques facilitant la lecture et la comparaison des performances.
Filtres personnalisables permettant une analyse ciblée par utilisateur.
Outil déployable et maintenable pour accompagner le pilotage opérationnel de l’entreprise.
